FAQ

Frequently Asked Questions

Everything you need to know.

Does this include automated daily updates?
No. The Basic Setup is designed for one-time analysis engagements. It pulls your data once, cleans it, and prepares it for immediate use. If you need daily automated updates, you should consider the Full Pipeline + Automation bundle.
Which platforms can you connect?
We can connect Shopify, GA4, Meta Ads, Google Ads, and Klaviyo. This basic bundle includes 2-3 platforms of your choice. If you need all platforms connected, please look at the Full Pipeline Setup.
Is my data secure?
Absolutely. We use read-only API access and follow strict security protocols. We do not store your credentials in plain text, and we never modify your live business data.
