FAQ

Frequently Asked Questions

What is included in the $850 starting price?
The starting price covers a standard data pipeline and custom dashboard setup using up to five standard data sources within an agreed dashboard scope.
Can the dashboard include sales, marketing, customers, products, and profitability?
Yes. These areas can be included as dashboard views where the required data is available. The final scope depends on the number of KPIs, calculations, pages, and data relationships required.
Does five data sources mean five dashboard pages?
No. Data sources are where the data comes from. Dashboard views are the business areas created from that data. One source can support several dashboard views, and several sources may be combined into one view.
Can Shopify, GA4, Meta Ads, and Google Ads be connected?
Yes, where the required access and data are available.
Will the dashboard show true profit?
Only when reliable cost data is available. Without product costs, shipping, payment fees, discounts, refunds, returns, and other relevant cost inputs, the dashboard may show revenue and profitability signals rather than a complete profit figure.
Will the dashboard update automatically?
Not in the standard setup. Automated updates are available through the Automated Scheduling, Refresh Monitoring & Error Alerts add-on.
Will I receive error alerts?
The standard setup includes initial validation and an initial pipeline error check. Live scheduled-refresh and failure alerts require the automation add-on.
Can I add audit automation later?
Yes. Marketing, retention, product, profitability, and operations automation can be added later, subject to data availability and technical scope.
Does audit automation include a written insight report?
The selected audit automation module may include text-based insight summaries and basic recommendations inside the dashboard or agreed reporting output. The depth depends on the selected module and scope.
Can I add another data source later?
Yes. Additional sources can be added later, subject to compatibility, data complexity, and additional scope.
Can I change the KPIs later?
Yes. KPI changes or additional calculations can be scoped after the initial setup. Major dashboard redesigns or new data models may require an additional fee.
Are cloud and software costs included?
No. Cloud hosting, software, API, and third-party platform costs are separate unless explicitly included in the proposal.
Is ongoing maintenance included?
No. The setup includes the initial build and handover. Ongoing maintenance can be scoped separately.
How long does setup take?
The standard dashboard setup typically takes 5–7 business days after the required access and data are available.
